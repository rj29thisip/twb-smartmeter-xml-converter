# TWB Smart Meter XML Converter
An automated module part of https://github.com/rj29thisip/twb-online-billing-management-system.
Improves operational efficiency and costing by reducing server (integrated with webapp) and removing manual CSV processes. 
This module automatically processes XML produced customer readings to required data format and directly updates database for billing algorithm ingestion.
